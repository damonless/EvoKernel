## Symptom
1) Workspaces with 600+ token coreDigest lost Section 5 micro-tools and on-demand L2 SKILL.md files (>1500 tokens) triggered false TOKEN_BUDGET_BLOAT (Issues #14, #16); 2) Switching git branches or renaming symbols on main after branching a sibling branch caused memories from sibling branches to be falsely marked [STALE] and fail agy-config-auditor (Issue #16); 3) Read-only diagnostic sessions (>=10 reads), AbsolutePath/SearchPath reads, call_mcp_tool wrappers, and rhetorical counter-questions missed crystallization reminders in CLI hooks (Issues #15-#16).

## Root Cause
1) Issues #10-#14: agy-config-auditor compared core-invariants.md in Split-Brain, failed on Class.method or file:symbol targets, and conflated maxCoreRuleTokens (1500) with static seed tokens; 2) Issues #14-#15: antigravity_hook.mjs and src/cli/hook.ts missed read-only diagnostic investigations (>=10 reads with <4 edits), rhetorical counter-questions, AbsolutePath/SearchPath meta exclusions, and call_mcp_tool wrapper payloads; 3) Issue #16: verifyMemoryFreshness and agy-config-auditor checked symbols only against current HEAD working tree without checking git merge-base --is-ancestor or sibling branch tips when symbols were renamed on main after branching, while runAudit applied the 1500-token Always-On rule limit to on-demand L2 SKILL.md playbooks.

## Solution
1) Decouple Section 4 maxCoreRuleTokens (1500) from MAX_TOOLS_CATALOG_TOKENS (350) and decouple on-demand L2 SKILL.md per-file limit (Math.max(tokenBudgetLimit * 2, 3000)) in src/cli/audit.ts; 2) Unify read-only diagnostic tracking (unproposed_read_count >= 10 with editCount < 4), AbsolutePath/SearchPath/SearchDirectory meta exclusions, call_mcp_tool wrapper handling, and CORRECTION_REGEX counter-question detection across antigravity_hook.mjs and src/cli/hook.ts (handlePostTool / handleStop); 3) Implement 3-tier Git-topology-aware memory verification (VERIFIED -> OTHER_BRANCH via git show on non-ancestor created_commit or sibling created_branch tip -> STALE) across src/core/memory.ts, src/core/telemetry.ts, src/mcp/handlers.ts, and agy-config-auditor.

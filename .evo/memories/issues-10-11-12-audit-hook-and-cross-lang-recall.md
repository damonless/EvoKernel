## Symptom
1) Subdirectory monorepo .evo/ workspaces failed multi-branch OTHER_BRANCH verification (git show <rev>:<path> resolved from repo root instead of cwd), NTFS/APFS path casing drift broke Git tree lookups, and legacy pre-commit memories lacked descendant branch discovery (Issue #17); 2) Passing --token-budget / options.tokenBudgetLimit collapsed L2 SKILL.md skillBudgetLimit down to the rule limit (Issues #16-#17); 3) Read-only diagnostic sessions and rhetorical counter-questions missed crystallization reminders (Issues #10-#15).

## Root Cause
1) Issues #10-#15: agy-config-auditor conflated maxCoreRuleTokens with seed tokens and hardcoded src/lib fallback dirs, while hooks missed read-only diagnostics (>=10 reads, <4 edits) and counter-questions; 2) Issues #16-#17: git show <rev>:<path> ignored cwd in subdirectory workspaces without a ./ prefix, NTFS/APFS stored caller casing instead of real on-disk Git casing, legacy memories without created_branch lacked descendant branch discovery on pre-commit lag, and runAudit coupled skillBudgetLimit to options.tokenBudgetLimit.

## Solution
1) Prefix cwd-relative Git lookups with ./ (git show <rev>:./<path>) across src/core/memory.ts, src/mcp/handlers.ts, and agy-config-auditor, canonicalize both root and target paths via fs.realpathSync.native, add git ls-tree case-insensitive fallback, and discover descendant branch tips via git for-each-ref --contains only when created_branch is absent; 2) Decouple AuditOptions.skillBudgetLimit (options.skillBudgetLimit ?? Math.max(tokenBudgetLimit * 2, 3000)) with --token-budget/--skill-budget CLI flags and expand agy-config-auditor unhinted fallback across all workspace source directories; 3) Unify read-only diagnostic and rhetorical correction tracking across antigravity_hook.mjs and src/cli/hook.ts.

## Symptom
1) agy-config-auditor exited 1 on core-invariants.md divergence, upgraded scoped rules lost transfer_scenarios, evo_compact bypassed Gate 1.5 and Clause Diff, and Chinese clause edits triggered 100% false-positive orthogonal clause warnings (Issue #10). 2) Multi-step Antigravity turns lost evolution reminders after step 1, double-JSON args broke path/tool matching, and .xls/.xlsx deliverable feedback failed to trigger crystallization (Issue #11). 3) Chinese hardware queries ('CN3008 12V 调试电源 电源测试口 电压') returned 0 hits for English hardware tools ('3ku-hw-query'), workspace tools were invisible in AGENTS.md/GEMINI.md, and duplicate rule IDs crashed capability_fts_fallback with UNIQUE constraint failed (Issue #12).

## Root Cause
1) Issue #10: agy-config-auditor compared core-invariants.md in Split-Brain and lacked backtick/comment checks; ensureGlobalFallbackSeeded skipped updating changed seed files; evaluateAndCommit lost transfer_scenarios on upgrade and bypassed Gate 1.5/Clause Diff on evo_compact; tokenizeClauseText treated CJK sentences as single tokens. 2) Issue #11: antigravity_hook.mjs consumed lastCorrectionStep on the first PreInvocation before Stop, failed to unquote double-JSON-serialized transcript args, ignored /scratch/ scripts and command error recovery, and AntigravityAdapter did not install .agents/hooks.json. 3) Issue #12: extractQueryTokens lacked ZH<->EN technical synonyms and PCB designator/unit expansion; tool manifests lacked tags and ID/schema FTS indexing; syncManagedRuleBlocks omitted workspace tool L0 catalog; capability_fts_fallback used plain INSERT without deduplicating rule IDs across rules/ and rules/scoped/.

## Solution
1) Exclude core-invariants.md in Audit 4, sync seed files in ensureGlobalFallbackSeeded, inherit transfer_scenarios on rule upgrade/compact, enforce Gate 1.5 and preserve supersededRules clause diff in evo_compact, and use CJK 2-grams with stripped Case Anchors in tokenizeClauseText. 2) Defer clearing correction state until Stop or evo_propose in antigravity_hook.mjs, unquote double-JSON transcript strings, track /scratch/ scripts and command error-recovery loops, and deploy .agents/hooks.json in AntigravityAdapter. 3) Expand PCB designators/units and bilingual synonyms in extractQueryTokens, persist and index tool tags/ID/schema properties, inject Section 5 tool catalog in syncManagedRuleBlocks + handleSearch footer, and deduplicate listRules/INSERT OR REPLACE in capability_fts_fallback.

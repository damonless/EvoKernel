## Symptom
Issue #9 Red-Team Audit, Windows/roots MCP proxy handshakes, external repo CLI/MCP path resolution, Claude Code official PostToolUse/Stop nested hook schema & inner hook uninstallation, one-click third-party MCP virtualization (evo virtualize including .codex/config.toml env/comments), and zero-dependency GitHub Actions CI.

## Root Cause
1) Issue #9 Round 3/4 + Retrospective proxy gaps: handleRun resolved cachedExtTool before awaiting ensureExternalToolsSynced, Windows spawn lacked .cmd/.bat PATH resolution, and MCP initialize omitted roots capability/rootUri; 2) External repo initialization hardcoded ./scripts/boot-mcp.mjs even when run outside EvoKernel's repo, upsertClaudeSettings wrote flat post-tool/stop strings instead of Claude Code's official PostToolUse/Stop nested matcher-hooks arrays, and removeClaudeSettings dropped shared matcher objects instead of filtering inner entry.hooks; 3) Users with multiple third-party stdio MCPs (including .codex/config.toml with env sub-tables and multi-line arrays) suffered Always-On schema bloat without a one-click folding/restore CLI command, and .github/workflows/{ci,publish}.yml failed on GitHub Actions due to cache: 'npm' and npm ci in a zero-dependency repo without package-lock.json.

## Solution
1) Resolve .cmd/.bat/.exe paths via resolveWindowsSpawnCommand, advertise roots capability + rootUri in McpClientConnection.connect(), and support both ext__<server>__<tool> and mcp:<server>:<tool>; 2) Add resolveInstalledEvoKernelRoot, resolveEvoMcpLaunchConfig, and resolveEvoHookCommand in src/cli/harness.ts for external repositories, forward hook subcommands in scripts/boot-mcp.mjs, emit Claude Code's official PostToolUse and Stop nested matcher-hooks structure in upsertClaudeSettings, and filter inner entry.hooks in removeClaudeSettings; 3) Add evo virtualize (--dry-run, --restore) in src/cli/virtualize.ts with bracket-depth/env-aware .codex/config.toml parsing and pool-scoped restoration, and remove cache: 'npm' / npm ci from zero-dependency GitHub Actions workflows.

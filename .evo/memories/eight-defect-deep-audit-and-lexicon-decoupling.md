## Symptom
1) External tool (ext__*) hit_count and outcomes reset to 0 on syncFromDisk or fail to sync when .cache/external_tools.json updates; 2) Hardware/PCB vocabulary hardcoded in generic telemetry.ts and odd-length Chinese phrases (写提交规范) fail Gate 3 similarity due to phase-shifted bigrams; 3) C/C++ #ifdef...}#else...}#endif and #if 0 dead code truncate AST blocks, while Go receiver methods without classHint merge across distinct structs; 4) Rogue --self-test corrupting dirty files >512KB or creating nested directories leaves disk damaged or polluted; 5) Reflect.get/parenthesized join bypass Gate 1 while forward-slash Windows user paths in memory titles/logs trigger false positives; 6) Hung/failing downstream MCP servers leak processes, cache dead connections, or retain stale tools when disabled.

## Root Cause
1) syncFromDisk deleted orphan telemetry rows before adding externalTools (ext__*) to activeIds and computeDiskSyncDigest checked external-tools.json instead of .cache/external_tools.json; 2) telemetry.ts hardcoded hardware/PCB synonyms in the generic kernel and tokenizeForSimilarity used non-overlapping CJK regex match(/[\u4e00-\u9fff]{1,2}/g) causing odd-length phase shift; 3) findBraceBlockEnd returned prematurely when braceDepth reached 0 inside an #ifdef branch before #else/#endif, ignored #if 0 dead code, and merged unrelated Go receiver methods when classHint was omitted; 4) Gate 2 --self-test rollback left newly created empty parent directories behind, lacked git status fallback at depth/file limits, and risked overwriting dirty uncommitted files >512KB via git checkout --; 5) Gate 1 missed Reflect.get, parenthesized array .join(), and sys.modules getattr, while scrubLocalUserPaths missed forward-slash Windows user paths and memory title; 6) discoverAllDownstreamTools ran serially, cached failed connections in McpProxyManager, and failed to purge cached tools when all externalServers were disabled; 7) evaluateBaselineFitness was skipped when probeCmd was passed and lacked CJK keyword-stuffing detection.

## Solution
1) Add externalTools to activeIds before telemetry cleanup, include .cache/external_tools.json & lexicon.json in computeDiskSyncDigest, and diff capability_fts incrementally with clean force-rebuild; 2) Move hardware lexicon to templates/lexicons/embedded-hardware.json, add src/core/lexicon.ts with dual-path .evo/lexicon.json loader, and use overlapping CJK bigrams in tokenizeForSimilarity; 3) Upgrade ppStack in findBraceBlockEnd for #ifdef/#else closing braces and #if 0 dead code, restrict overload merging to overload-capable languages or explicit classHint, and support multiline Go receivers; 4) Add captureWorkspaceRollbackSnapshot & restoreWorkspaceFromSnapshot (preserving dirty files up to 32MB, cleaning empty parent dirs, git status fallback, and UI/IDE run-tool-test parity); 5) Harden DANGEROUS_PATTERNS and scrub both backslash and forward-slash user paths in memory title/body to <USER_HOME>; 6) Probe downstream MCP servers concurrently via Promise.allSettled, close hung processes on timeout, evict dead connections, and purge cached tools when all servers are disabled; 7) Enforce ASCII + CJK keyword-stuffing penalty in evaluateBaselineFitness across both probeCmd and offline regimes.

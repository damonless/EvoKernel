## Symptom
1) Deep/excess dirty files deleted by fs.unlinkSync on --self-test rollback when hitLimit triggers, recreated pre-deleted files ignored, or untouched files flagged on maxFiles window shift; 2) Reusable worktree fails with exit 128 on 2nd probe, shifts HEAD on candidate commits, or leaks .evo across candidates; 3) Deleted classHint method binds to other class/receiver/C++ scope, overloads merge across classes, #if 0 in block comments or paired #ifdef { } corrupts findBraceBlockEnd, Rust lifetimes eat control flow or dropped string placeholders collide in computeStructuralSkeletonHash, and // C:\temp\ or URL colons corrupt stripCStyleComments; 4) embedded-hardware.json collapses voltage/current/adc into interface and pin/hardware into debug; 5) checkMcpGatewayConfigs reports any .mcp.json as registered, evo --workspace <dir> fails with unknown command, boot-mcp --workspace hangs in MCP mode, and BOOT_MCP_STUB truncates JSON args containing & or () on Windows cmd.exe.

## Root Cause
1) captureWorkspaceRollbackSnapshot omits gitDirtyFiles when hitLimit triggers, adds non-existent deleted files to gitDirtyFiles, and flags maxFiles window-shifted untouched files as mutated; 2) probeCandidateInWorktree calls git worktree add unconditionally on reused wtDir, resets to wtDir HEAD instead of wsRoot HEAD, and skips wtEvoDir cleanup on fallback; 3) findAllSymbolDeclarationsInLines falls back to whole-file scan on missing classHint methods and misses Rust impl with lifetime commas/bounds; 4) stripCStyleComments treats URL colons and >1-char single-quoted strings as Rust lifetimes and // \\ as line continuations in non-C languages, while computeStructuralSkeletonHash drops string placeholders; 5) compileLexiconConfig performs transitive closure across 1-to-N synonyms; 6) checkMcpGatewayConfigs unconditionally marks .mcp.json as registered, normalizeLeadingFlags/boot-mcp misroute leading flags, and quoteWinArg escapes inner quotes for C CRT without escaping cmd.exe metacharacters outside toggled cmd quotes.

## Solution
1) Synchronize hitLimit gitDirtyFiles & GIT_STATUS:D handling in captureWorkspaceRollbackSnapshot, unlink recreated GIT_STATUS:* files, and verify on-disk computeFileMutationSig before flagging maxFiles window-shifted files in restoreWorkspaceFromSnapshot; 2) Reuse existing .git in probeCandidateInWorktree via targetHeadSha checkout/reset/clean, wipe wtEvoDir unconditionally, and wire reusableWorktreeDir across runOptimizationCycle; 3) Enforce classHint & otherClassRanges isolation (including Rust impl & C++ out-of-line), same-container overload grouping, C/C++/C#-scoped cleanLine ppStack with unclosedIfdefBraceDelta, V1/V2 ast_hash check in verifyMemoryFreshness, keepStringPlaceholder in computeStructuralSkeletonHash, and URL-safe ext-aware stripCStyleComments; 4) Restrict compileLexiconConfig canonical pairing to non-ASCII keys -> synList[0]; 5) Remove .mcp.json false positive, fix normalizeLeadingFlags/boot-mcp flag routing, and track inCmdQuote in quoteWinArg to escape [&|<>^()] as ^^^<ch> outside cmd quotes under cmd.exe /d /s /c with windowsVerbatimArguments.

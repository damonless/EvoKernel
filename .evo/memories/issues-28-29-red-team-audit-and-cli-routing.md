## Symptom
1) Deep/excess dirty files deleted by fs.unlinkSync on --self-test rollback when hitLimit triggers; 2) Reusable worktree fails with exit 128 on 2nd probe and leaks .evo across candidates; 3) Deleted classHint method binds to other class/receiver, overloads merge across classes, #if 0 in block comments or paired #ifdef { } corrupts findBraceBlockEnd, Rust lifetimes eat control flow in computeStructuralSkeletonHash, and // C:\temp\ eats next line in TS/JS; 4) embedded-hardware.json collapses voltage/current/adc into interface and pin/hardware into debug; 5) checkMcpGatewayConfigs reports any .mcp.json as registered, evo --workspace <dir> fails with unknown command, and boot-mcp --workspace hangs in MCP mode.

## Root Cause
1) captureWorkspaceRollbackSnapshot omits gitDirtyFiles when hitLimit triggers and lacks GIT_STATUS:D parity with captureWorkspaceMutationSignature; 2) probeCandidateInWorktree calls git worktree add unconditionally on reused wtDir and skips wtEvoDir cleanup on fallback; 3) findAllSymbolDeclarationsInLines falls back to whole-file scan on missing classHint methods and misses Rust impl/Python class ranges; 4) stripCStyleComments treats >1-char single-quoted strings starting with letters as Rust lifetimes and // \\ as line continuations in non-C languages; 5) compileLexiconConfig performs transitive closure across 1-to-N synonyms; 6) checkMcpGatewayConfigs unconditionally marks .mcp.json as registered and normalizeLeadingFlags/boot-mcp misroute leading flags.

## Solution
1) Synchronize hitLimit gitDirtyFiles & GIT_STATUS:D handling in captureWorkspaceRollbackSnapshot and guard gitDirtyFiles against unlinkSync in restoreWorkspaceFromSnapshot; 2) Reuse existing .git in probeCandidateInWorktree via checkout/reset/clean, wipe wtEvoDir unconditionally, and wire reusableWorktreeDir across runOptimizationCycle; 3) Enforce classHint & otherClassRanges isolation (including Rust impl & Python blocks), same-container overload grouping, C/C++/C#-scoped cleanLine ppStack with unclosedIfdefBraceDelta, V1/V2 ast_hash check in verifyMemoryFreshness, and ext-aware stripCStyleComments; 4) Restrict compileLexiconConfig canonical pairing to non-ASCII keys -> synList[0]; 5) Remove .mcp.json false positive, fix normalizeLeadingFlags/boot-mcp flag routing, and use cmd.exe /d /s /c with windowsVerbatimArguments in BOOT_MCP_STUB.

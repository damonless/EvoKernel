## Symptom
1) Exported cockpit HTML with script-src 'sha256-...' blocked inline onclick handlers, triggered /\bon[a-z]+\s*=/i on unescaped onclick= inside serialized snapshot JSON, or threw SyntaxError on unescaped token strings; 2) evo score reported 0 pooled servers after evo virtualize wrote object-formatted .evo/mcp-pool.json; 3) redactSensitiveDiagnostics leaked hyphen-terminated tokens or truncated specific keys inside api_key assignments; 4) evo init slash commands collided with updatedFiles.length === 3 contract test; 5) server.json declared Apache-2.0 instead of MIT.

## Root Cause
1) Strict CSP script-src 'sha256-...' blocks HTML inline onclick= event attributes, serialized JSON containing literal onclick= strings triggers static on*= scanners unless = is escaped as \u003d, and template-interpolated JS strings bypass TypeScript syntax checks unless verified with node:vm Script; 2) inspectMcpTaxSnapshot only checked Array.isArray(poolData) instead of poolData.mcpServers object maps and keyed servers by name@source causing duplicate tax counts; 3) Regex word boundary \b fails after trailing hyphens in API tokens, and generic api_key= rules must run after specific prefix rules; 4) Adding slash command files to InitResult.updatedFiles breaks existing updatedFiles.length contract tests.

## Solution
1) Bind all UI handlers via addEventListener inside the SHA-256 hashed script, JSON-serialize token/snapshot with < escaped as \u003c and = escaped as \u003d, and validate inline script syntax via new vm.Script() in score-and-ui.test.ts; 2) Support both array and { mcpServers } object schemas in .evo/mcp-pool.json, top-level servers in .vscode/mcp.json, and deduplicate by canonical lowercase server name in inspectMcpTaxSnapshot; 3) Open existing telemetry.db with DatabaseSync({ readOnly: true }) across score, ui, audit, and doctor; 4) Track slash commands in InitResult.commandFiles without mutating updatedFiles; 5) Enforce license parity across all manifests in evo-release-preflight.

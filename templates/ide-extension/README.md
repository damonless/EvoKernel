# EvoKernel Workbench for VS Code

AST-Verified Cognitive Memory, Dynamic Context Virtualization & Deterministic Gatekeeper for AI Coding Agents.

## Features

- **EvoKernel Workbench**: Visual dashboard for inspecting and managing active project rules, skills, tools, and episodic fault memories.
- **AST Anti-Drift Verification**: Real-time structural fingerprint verification ensuring memory anchors never drift or hallucinate against current code symbols.
- **Context Health & Fragility Score**: Real-time token shielding metrics, Git fragility hotspots, and prompt tax savings.
- **Zero-Write Diagnostic Audits**: Fast white-box auditing without touching repository files.

## Getting Started

1. Open the Command Palette (`Ctrl+Shift+P` on Windows/Linux, `Cmd+Shift+P` on macOS).
2. Type and execute:
   - `EvoKernel: Open Workbench` (or alias `EvoKernel: Open Workbench (Legacy Alias)`)
3. View your project's active cognitive context, verified memory anchors, and Gatekeeper event stream.

## Commands

| Command | Title | Description |
|---|---|---|
| `evo.openWorkbench` | `EvoKernel: Open Workbench` | Opens the interactive EvoKernel Workbench Webview. |
| `evo.viewCockpit` | `EvoKernel: Open Workbench (Legacy Alias)` | Backward-compatible alias for opening the Workbench. |

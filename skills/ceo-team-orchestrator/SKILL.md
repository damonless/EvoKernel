## L1 Contract
- **Trigger**: When orchestrating a multi-role subagent team led by a Main Agent CEO to harden a codebase and upgrade its GitHub onboarding, UI, and visual/motion presentation.
- **Inputs**: Target repository workspace, S1 technical goals, and S2 market/visual goals.
- **Outputs**: Gate-verified S1 technical baseline, S2 programmatic motion graphics & 30s interactive showcase, streamlined Quick Start, and 100% passing test/preflight suite.

## L2 SOP
1. **Stage S1 — Technical Foundation Loop (`PM -> CEO -> Engineer -> QA`)**:
   - Spawn `S1 PM Subagent` (`flash`) to benchmark the project, identify technical/UX gaps, and define measurable Acceptance Gates (`GATE-1..N`).
   - CEO verifies PM findings against live source code to eliminate false positives, then dispatches `S1 Core Engineer` (`flash`) with file-scoped tasks.
   - Spawn `S1 QA Test Engineer` (`flash`) to execute independent black-box/white-box tests against `GATE-1..N`. Do not enter S2 until S1 gates pass 100%.
2. **Stage S2 — Market, Onboarding & Visual Motion Loop (`CMO -> CEO -> Art -> UI -> Engineer`)**:
   - Spawn `Senior CMO Subagent` (`inherit` / high-tier model) to analyze GitHub conversion bottlenecks, Quick Start friction, runtime requirements, and `video-shotcraft` shot recipes.
   - CEO slices S2 into conflict-free sequential packages:
     - **S2-A (`Art Subagent`, `flash`)**: Remove AI raster artifacts, build 60fps programmatic SVG motion graphics (`video-shotcraft` recipes + `R1/Q2/Q4/Q11` rules), and update `@2x` render scripts.
     - **S2-B (`UI Subagent`, `flash`)**: Build interactive theater modals, constellation/gauge animations, and verify strict CSP/script syntax.
     - **S2-C (`Full-Stack Engineer`, `flash`)**: Streamline 30-second Quick Start, add zero-upgrade runtime 1-liners, overhaul bilingual `README`s, refresh AST memories, render final assets, and run full test + preflight checks.
